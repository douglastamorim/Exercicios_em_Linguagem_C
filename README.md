# README

## Estudos de Linguagem C
Repositório criado para registrar minha evolução nos estudos da Linguagem C durante minha formação em Análise e Desenvolvimento de Sistemas (ADS).

## 📚 Sobre
Aqui estão reunidos códigos, projetos e exercícios desenvolvidos utilizando a linguagem C, focando na transição da lógica em Portugol para uma linguagem de programação compilada e de baixo nível.

## 🧠 Conteúdos praticados
* Sintaxe e estrutura básica em C
* Entrada e saída de dados (`scanf` e `printf`)
* Estruturas condicionais (`if/else` e `switch-case`)
* Estruturas de repetição (`while`, `do-while` e `for`)
* Manipulação de strings e caracteres
* Vetores (arrays unidimensionais) e Matrizes (arrays multidimensionais)
* Alocação dinâmica de memória e Ponteiros
* Criação de funções e procedimentos
* Manipulação de arquivos (`.txt`, `.dat`)

## 🛠️ Tecnologias e Ferramentas utilizadas
* Linguagem C
* Compilador GCC / Clang
* IDE/Editor: Code::Blocks
